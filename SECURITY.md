# Security Policy

This repository contains markdown skill packs only. Vulnerabilities that involve the **binary** belong in [cli](https://github.com/blotless/cli), [engine](https://github.com/blotless/engine), or [ast](https://github.com/blotless/ast).

## Reporting

**Do not** open a public issue for security reports.

Email **zikmanv@icloud.com** or use the advisory form on the affected Go repo.

Skill-pack issues (wrong PATH instructions, prompt injection in SKILL.md) can be described in the email as well.

**Initial response:** within 72 hours.
